## Crawde v0.1.2

A clearer tray icon, a refreshed project page, and fixes to keep your crab awake while Claude works.

### Fixed

- Active tool and subagent work keeps the crab awake even when process detection misses Claude or the original prompt is old.
- Startup events use Claude's supported command hook. Existing HTTP startup-hook configurations are repaired automatically.
- Single-chat bubbles sit closer to the pet, without unused pagination space or transparent sprite headroom.
- Settings show when hook activity last arrived, making connection problems easier to diagnose.

### Updated

- Dedicated high-resolution crab-claw tray icon, separate from the application icon, with matching README branding.
- README banner, quick navigation, release/download/CI/platform/framework/license badges, and concise setup and usage sections.
- Gently faster sleep animation and drifting “zzz.” Idle preserves the locally selected 5 fps speed.
- MIT license for application code and branding, with a separate notice for the supplied sprite artwork.

### Install

Download **Crawde_0.1.2_x64-setup.exe** below. A SHA-256 checksum is included.

After upgrading, quit and reopen Crawde, then restart existing Claude Code sessions so they load the repaired hooks. **Settings → Claude** reports when activity is received.

Supports Windows x64, Claude Code in the terminal, and the Code tab in Claude Desktop. WebView2 and the native Claude Code CLI are required. Regular Claude Chat and WSL/remote activity forwarding are outside this release's scope.
