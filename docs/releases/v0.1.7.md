## Crawde v0.1.7

Both right-click menus now show one update action: **Up to date (vx.y.z)** or **Install latest update (vx.y.z)**. When an update is available, click it to download, verify, launch the installer, and close Crawde.

Crawde always checks for updates on launch. Checking does not automatically install anything. Failed checks offer a retry and leave Crawde running.
