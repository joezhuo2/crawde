# Original sprite artwork

The `Crab_*.png` sheets and `CrabComplete.gif` were supplied with this project.
They retain their original creators' terms and are not included in the MIT
license for Crawde's application code and branding assets. The project did not
include an original artist credit or license file for these sheets.

The dedicated tray icon and banner in `assets/` and `src-tauri/icons/tray*.png`
are Crawde branding assets generated by `scripts/make-branding.mjs` and are
covered by the repository's MIT license.
