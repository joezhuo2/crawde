## Crawde v0.1.3

Fixes the invisible crab in the Windows installer, where only the drifting “zzz” letters could appear.

### Fixed

- Sprite sheets are now packaged as local PNG files. Previously, Vite embedded the small sheets as data URLs, which the native Content Security Policy blocked.
- All crab animations, including idle and sleep, use the corrected asset packaging.

### Release checks

- Every production build verifies that all five sprite sheets are included, referenced, and compatible with the app's image policy.
- Production previews now enforce the same Content Security Policy as the native app.

### Install

Download **Crawde_0.1.3_x64-setup.exe** below, quit the existing Crawde process from **Settings → About → Quit Crawde**, and install the update. Your preferences and saved positions are preserved. A SHA-256 checksum is included.
