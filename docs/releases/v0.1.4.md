## Crawde v0.1.4

Right-click the crab or tray icon to check for updates or close and install the latest update. Downloads are verified against the release SHA-256 checksum; Crawde stays open if the download or installer launch fails.

For this first upgrade from v0.1.3, download Crawde_0.1.4_x64-setup.exe, quit Crawde from Settings → About, and run the installer. Preferences and positions are preserved.
