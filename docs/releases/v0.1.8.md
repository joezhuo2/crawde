# Crawde 0.1.8

Claude Code sessions in Ubuntu and other WSL distros now drive Crawde on Windows.

After updating, choose **Reinstall activity hooks** and restart existing Claude sessions.
WSL requires Python 3 and enabled Windows executable interop. Activity forwarding
uses the Windows loopback bridge, with no firewall changes. Clicking a WSL chat
resumes it in its original distro and Linux project; new chats retain that context.

The installer remains a Windows application; this release does not add a native
Linux app or forwarding from separate Linux machines.
